=>Instead of calling 3 services one by one..use docker compose which helps to start all three services at a time.
=>docker-compose will pull all the 3 image full registry then start..Three services are tax-service,price-srevice,tax-price-calculation-react.

=>Docker will automatically pull all 3 images from DockerHub since they don't exist locally: docker-compose up -d
=>Then verify,check all 3 containers running: docker ps

# check logs
docker logs tax-service
docker logs price-service
docker logs tax-price-app

Then open browser: http://localhost:5173

=>then stop docker compose : docker-compose down (That's it! It will stop and remove all 3 containers at once.)
=>If you also want to remove images: docker-compose down --rmi all
